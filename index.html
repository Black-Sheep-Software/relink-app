01   /   The idea

A familiar controller.
A new connection.

ReLink is a controller companion for your computer, designed to help your Stadia Controller work with compatible games.

Our goal is simple: give good hardware more life, with local play that doesn’t depend on a cloud account or subscription.

What you’ll need

A Stadia Controller and a Linux computer for the currently tested paths. USB and Bluetooth input have been tested; Windows support is still in development.

About native Wi-Fi

Native Wi-Fi is experimental. The current Linux setup uses a separate, dedicated Wi-Fi adapter to create an isolated controller network.

03   /   Project status

Good progress.
More work to do.

We’ve demonstrated controller input across all three connections on Linux, including an early native Wi-Fi test in a game.

We’re continuing to improve reliability and ease of use. Windows support is also in development. ReLink is not yet available as a finished product.
